## 2. 最值得记住的结论

1. **伤害增幅不是一个总百分比。**攻击力、技能倍率、增伤、暴击、防御、抗性、易伤等作用在不同位置；名称都像“提高伤害”，计算方式可能完全不同。
2. **同区通常相加，区间相乘，但必须先检查适用条件。**火属性增伤与通用增伤可以共同作用于火伤；终结技增伤不能自动作用于由终结技触发的所有额外伤害。
3. **不能让所有伤害共用同一套完整公式。**普通直伤、技能施加的 DOT、击破 DOT、击破瞬间伤害和超击破，对攻击力、暴击、增伤、击破特攻及削韧的依赖不同。
4. **“稀释”是相对收益下降。**已有很多增伤时，再加同样的增伤，实际百分比提升会变小；这不等于新增属性失效或被扣掉。
5. **附加伤害、追加攻击、一次行动中的多段伤害不是同一件事。**需要分别判断数值来源、伤害类型及是否算独立攻击。
6. **伤害总量还取决于出手机会。**速度、拉条、充能、追加攻击触发频率和击破窗口影响一定行动值内的输出，不能只比较某一击的数字。

## 4. 普通直伤：每个乘区分别做什么

### 4.1 总体公式

**【视频内容，约 00:50、07:20】**

```text
普通直伤
= 攻击区 × 倍率区 × 增伤区 × 双暴区
  × 防御区 × 抗性区 × 易伤区 × 减伤区
  × 特殊乘区（存在相应机制时）
```

这是视频以攻击力倍率伤害为主体的教学表达。**【整理推导】**如果某个技能按生命值、防御力或多个属性缩放，应先按该技能规则构造基础伤害，不能因为公式写着“攻击区”就强行读取攻击力。

| 部分 | 通俗含义 | 常见误解 |
| --- | --- | --- |
| 攻击区 | 本次伤害使用的攻击力数值 | 攻击力提高 20% 不等于最终伤害必然提高 20% |
| 倍率区 | 技能对属性的利用比例 | 200% 攻击力倍率与“增伤 200%”不是同一字段 |
| 增伤区 | 符合当前伤害条件的伤害加成 | 不能把所有技能类型加成都累加进来 |
| 双暴区 | 是否暴击及暴击额外伤害 | 暴击期望不能用来替代每次实际伤害的判定 |
| 防御区 | 等级、敌方防御、减防和无视防御形成的系数 | 减防 40% 不等于最终伤害直接乘 1.4 |
| 抗性区 | 对应伤害属性的抗性与穿透 | 减抗与减防不是同一计算过程 |
| 易伤区 | 目标受到某类伤害增加 | 与攻击方的“造成伤害提高”不是同一区 |
| 减伤区 | 视频重点讲解韧性状态带来的修正 | 不能把所有护盾、减伤技能都直接套成 0.9 |
| 特殊乘区 | 明确声明的额外规则 | 不能只因某个效果来自天赋就认定它独立相乘 |

### 4.2 攻击力：百分比加成通常乘白字

**【视频内容，约 01:00–01:30】**

```text
基础攻击力 = 角色基础攻击力 + 光锥基础攻击力
面板攻击力 = 基础攻击力 × (1 + 攻击力百分比加成之和)
             + 固定攻击力加成之和
```

**【整理推导示例】**基础攻击力为 1,000，已有 50% 攻击力加成，固定攻击力增加 200：

```text
面板攻击力 = 1000 × 1.5 + 200 = 1700
再增加 20% 攻击力：1000 × 1.7 + 200 = 1900
相对提升 = 1900 / 1700 - 1 ≈ 11.76%
```

角色提供的攻击增益还可能有施加者属性、受益者基础属性、上限等限制；不能只看描述中一个百分比。

### 4.3 增伤：先筛选，再相加

**【视频内容，约 01:40–02:10】**

```text
增伤系数 = 1 + Σ(对当前这笔伤害有效的增伤)
```

可能包括通用伤害、对应元素、普攻、战技、终结技或追加攻击等限定加成。

**【整理推导示例】**一次火属性终结技伤害，满足通用增伤 20%、火伤 30%、终结技增伤 40%：

```text
增伤系数 = 1 + 0.2 + 0.3 + 0.4 = 1.9
```

若另有普攻增伤 50%，这笔伤害不符合条件，不能加入。这里也不是 `1.2 × 1.3 × 1.4`。

### 4.4 暴击：区分实际值与期望值

**【视频内容，约 02:20–02:48】**

```text
未暴击系数 = 1
暴击系数 = 1 + 暴击伤害
平均暴击系数 = 1 + 暴击率 × 暴击伤害
```

暴击率和暴击伤害用小数表达，例如 80% 和 150% 对应 `0.8`、`1.5`。平均系数为 `1 + 0.8 × 1.5 = 2.2`；单次实际结果仍可能是 1 倍或 2.5 倍。

视频提出，在总词条预算不变的条件下，暴击率与暴击伤害约 `1:2` 时收益较好。**这个结论有条件：**词条兑换关系相应成立，计入战斗中的有效加成，暴击率没有溢出，技能也不存在固定暴击等特殊规则。不是所有角色都必须机械追求面板 `1:2`。

**【待核验】**本视频不能单独确定所有多段技能是按段独立暴击，还是某些效果共享一次判定。多段数字、动画命中和逻辑判定次数不能直接画等号。

### 4.5 抗性：负抗性仍能提高伤害

**【视频内容，约 03:50–05:00】**

```text
有效抗性 = 原始对应属性抗性 + 抗性提高 - 抗性降低 - 对应抗性穿透
抗性系数 = 1 - 有效抗性
```

视频用高冰抗目标说明：

| 条件 | 有效抗性 | 抗性系数 |
| --- | ---: | ---: |
| 原始抗性 60% | 0.60 | 0.40 |
| 再有 25% 抗性穿透 | 0.35 | 0.65 |
| 再有 30% 减抗 | 0.05 | 0.95 |

**【整理推导】**从 0.40 到 0.65，实际伤害提高 `62.5%`，不是 25%；增益效果取决于原来的抗性。

视频也明确区分了与《原神》的负抗性处理：原始抗性为 0、穿透 25% 时，其举例系数为 `1.25`，不能移植“负抗性减半”的计算习惯。

**【待核验】**这里不据视频推定所有抗性上下限、极端取值分段规则或特殊敌人例外；视频示例范围外的实现边界需要另查。

### 4.6 易伤：挂在受伤条件上的增幅

**【视频内容，约 05:10–05:40】**

```text
易伤系数 = 1 + Σ(对当前伤害有效的易伤)
```

通用易伤与只对特定伤害类型生效的易伤需要分别判断。攻击方的“造成伤害提高”和目标的“受到伤害提高”，即使描述都含“伤害提高”，也不能统一累加。

**【整理推导示例】**攻击方增伤 50%，目标易伤 20%，两区贡献为 `1.5 × 1.2 = 1.8`，不是 `1 + 0.5 + 0.2 = 1.7`。

### 4.7 韧性减伤：要看伤害结算时点

**【视频内容，05:50–06:00】**视频给出的常态韧性修正是：

- 未击破状态：系数 `0.9`。
- 击破后状态：系数 `1`。
- **05:56–05:58 明确说明：击破那一下造成的击破伤害按 `0.9` 计算。**
- 随后以波提欧天赋说明，击破后另行结算的伤害与击破瞬间并不处于相同时点。

**【整理推导】**不能看到行动结束时目标已经击破，就把这个行动内所有伤害统一改用 1。应区分每笔伤害实际依赖的阶段。

**【待核验】**击破瞬间使用 0.9 是作者在该视频中的明确说法，本次没有另行做游戏实测校验。完整“减伤系统”还可能包含其他机制；视频的 0.9/1 不能作为所有减伤来源的叠加规则。

### 4.8 防御：减防和无视防御进入分母

**【视频内容，约 06:10–07:00】**按视频展示的敌方防御模型：

```text
攻击方等级系数 C = 200 + 10 × 攻击方等级
敌方基础防御 D₀ = 200 + 10 × 敌方等级
有效防御 D = D₀ × [1 - (减防比例 + 无视防御比例)]
防御系数 = C / (C + D)
```

视频强调减防与无视防御合计按最多 100% 理解，不能超过后继续获得这一模型内的收益。此处是视频使用的敌方示例模型，不代表玩家最终防御属性也只有等级这一项。

以视频中的 80 级攻击方、95 级敌人为例：

```text
C = 1000，D₀ = 1150
无减防：1000 / (1000 + 1150) ≈ 0.4651
40% 减防 + 20% 无视防御：D = 1150 × 0.4 = 460
防御系数：1000 / 1460 ≈ 0.6849
```

**【整理推导】**实际相对提升约 `47.26%`。既不是直接提高 60% 伤害，也不是使伤害变为原来的 40%。

### 4.9 特殊乘区不能靠名字推断

**【视频内容，约 07:10–07:20】**普通公式之外还存在特殊机制；视频用角色和敌方机制举例说明。

**【整理推导】**“天赋”“行迹”“遗器”“技能 Buff”描述的是来源，不直接决定乘区。某个天赋可以增加攻击力，也可以增加暴击率、提供易伤、改变技能倍率或额外产生一笔伤害。只有规则明确说明时，才能把效果视作独立乘数。

## 5. 持续伤害：技能 DOT 与击破 DOT 必须分开

### 5.1 技能施加的 DOT

**【视频内容，07:33–07:50】**以卡芙卡、黑天鹅相关持续伤害为例，视频保留攻击、倍率、增伤、防御、抗性、易伤和减伤，去掉普通双暴部分：

```text
技能 DOT ≈ 攻击区 × DOT 倍率区 × 适用增伤区
           × 防御区 × 抗性区 × 易伤区 × 减伤区
```

因此，“DOT 不暴击”不等于“DOT 不吃增伤”。对应元素加成等仍可能有效，但要检查具体伤害的适用条件。

视频后段还提到特殊玩法可能改变 DOT 暴击规则。因此，上述是其讲解的常规情况，不是任何模式都不可变的定律。

### 5.2 击破产生的 DOT

**【视频内容，约 08:00–09:15】**物理、火、雷、风击破后的持续伤害，需要按击破体系计算。核心输入变为击破者等级对应的基础系数、击破特攻及对应元素规则，不再照搬普通攻击力技能倍率。

视频的 80 级击破系数表显示约 **3767**。本文只保留画面上的近似值，不把它当作可直接用于高精度实现的完整常量。

物理裂伤尤其不能简单理解为固定倍率：视频给出精英敌人最大生命值占比与另一上限表达式取较小值的情况。**不要把精英示例中的 7% 最大生命值写成所有敌人的统一规则。**

### 5.3 来源、快照与结算时点

**【视频内容，08:52–09:14】**作者说明：

- 所讨论的击破 DOT 持续两个回合，并“锁击破特攻”。
- 伤害结算时仍会计算减防、减抗、易伤等因素。
- 同角色再次击破涉及持续回合刷新；风化另有层数处理。
- 不同角色造成的击破 DOT 可以分别显示和计算。

**【整理推导】**一个持续效果可以同时使用“施加时保存的部分属性”和“结算时读取的部分状态”，不一定全部快照，也不一定全部动态。

**【待核验】**上面是视频明确表达的规则。当前版本每种 DOT 的快照字段、刷新方式、层数上限、持续回合扣除时机以及引爆如何读取属性，需要逐项核验。不能把这段击破 DOT 说明推广成所有技能 DOT 的统一快照规则。

## 6. 击破与超击破

### 6.1 击破瞬间伤害

**【视频内容，约 10:00】**

```text
击破伤害
= 等级击破系数 B × 元素系数 E
  × [(目标韧性条长度 + 20) / 40]
  × (1 + 击破特攻)
  × 防御区 × 抗性区 × 易伤区 × 减伤区
```

这里“韧性条长度”应与该韧性条的总量联系，不能替换成触发击破前仅剩的几点韧性。

| 击破元素 | 视频列出的瞬间伤害元素系数 |
| --- | ---: |
| 物理、火 | 2 |
| 风 | 1.5 |
| 雷、冰 | 1 |
| 量子、虚数 | 0.5 |

这些系数对应**击破瞬间**，不能不加区分地用于后续 DOT、纠缠伤害或超击破。

**单位提醒：**视频使用其当时展示的削韧数值尺度，公式含 `(韧性 + 20) / 40`、超击破含 `削韧 / 10`。如果另一份资料用不同尺度，必须统一分子与常量，不能直接拼接。例如若所有韧性数值整体放大为三倍，数学等价的分式应同时改为 `(韧性 + 60) / 120` 与 `削韧 / 30`。这是单位换算示例，不是另加伤害规则。

### 6.2 击破后的效果不都是 DOT

**【视频内容，约 10:50–11:50】**

- 火、雷、风、物理具有对应击破 DOT。
- 冰的冻结后续伤害、量子的纠缠伤害被视频区分为附加伤害，不应直接归入 DOT。
- 量子、虚数还涉及额外行动延后或控制效果。
- 视频提及击破的基础行动延后以及元素追加影响。

因此，“敌人身上挂了一个状态，之后掉血”不足以判断它一定是 DOT。伤害分类、触发时机、控制效果应分开认识。

本文不整理全部控制百分比及纠缠层数公式，避免把抽样画面中不完整的条件误写成完整规格。

### 6.3 虚韧性说明了什么

**【视频内容，约 10:10–10:30】**视频讨论的当时虚韧性有三个重点：

1. 仍视作击破状态。
2. 没有常态未击破韧性减伤。
3. 可以继续打出超击破。

画面还展示了“原韧性长度的 25%”及最低韧性条件，但这是该段讨论的具体机制背景，**不能作为所有未来虚韧性来源的统一比例**。

**【整理推导】**“存在一条可削减的条”与“处于普通未击破状态”可以不是同一个条件。不要仅凭 UI 是否有条来判断全部伤害规则。

### 6.4 超击破：看有效削韧量，不看目标最大韧性

**【视频内容，约 12:00–13:40】**

```text
超击破伤害
= 等级击破系数 B
  × 超击破转化倍率
  × (符合结算条件的削韧量 / 10)
  × 对该超击破来源适用的特殊系数
  × (1 + 击破特攻)
  × 防御区 × 抗性区 × 易伤区
```

它与普通击破的核心区别：

| 问题 | 击破瞬间伤害 | 超击破 |
| --- | --- | --- |
| 是否依赖元素击破系数 | 视频公式中有 | 视频公式中没有 |
| 是否依赖敌人总韧性 | 有韧性长度因子 | 不使用该因子 |
| 是否依赖这次攻击的削韧量 | 不以本次削韧量直接替代总韧性因子 | 直接相关 |
| 是否需要击破特攻 | 是 | 是 |
| 是否直接套普通暴击、增伤 | 否 | 否 |
| 是否需要对应触发能力 | 击破产生 | 需要技能或队伍机制赋予超击破能力 |

视频在约 12:20 举出流萤 50%、乱破 60%、同谐主 100% 的转化倍率例子；这些只是当时讲解选取的技能条件，不能把数值当作角色所有情况下的唯一倍率。

视频还展示同谐主根据敌人数提供额外增幅。**这种来源专属修正不能自动乘到其他来源的全部超击破上。**同一次攻击中多个超击破来源，应分别判断自己的规则。

### 6.5 多段攻击与击破效率

**【视频内容，约 12:50–13:40】**进入击破状态的时点影响后续能够参与超击破的削韧部分；不能简单把整次技能总削韧全部计入超击破。

**【整理推导示例】**一个技能有五段削韧，各段基础削韧都为 10。如果前两段完成破韧，后续段能否形成超击破，与第四段才破韧的情况显然不同。具体击破当段是否还有可计部分、机制如何拆分，需要按实际规则确认，本文不凭示例补出内部结算实现。

击破效率提高可作用于削韧量，进而影响超击破基础。视频以波提欧说明，技能专属削韧提升与通用击破效率也可能属于不同计算环节，不能看到“削韧提高”就全部平铺相加。

## 7. 五种伤害的乘区对照

下表是视频常规规则的归纳；“不直接使用”不排除某个角色把属性转换成另一种有效属性。

| 输入或乘区 | 普通攻击力直伤 | 技能 DOT | 击破 DOT | 击破瞬间 | 超击破 |
| --- | --- | --- | --- | --- | --- |
| 攻击力 × 技能倍率 | 使用 | 通常使用对应 DOT 倍率 | 不直接使用 | 不直接使用 | 不直接使用 |
| 普通适用增伤 | 使用 | 使用 | 不直接使用 | 不直接使用 | 不直接使用 |
| 普通双暴 | 使用 | 常规不使用 | 常规不使用 | 常规不使用 | 常规不使用 |
| 等级击破系数 | 不使用 | 不使用 | 使用 | 使用 | 使用 |
| 击破特攻 | 不直接使用 | 不直接使用 | 使用 | 使用 | 使用 |
| 元素击破规则 | 不使用 | 不使用 | 按元素分别处理 | 使用元素系数 | 无普通元素系数 |
| 敌方最大韧性 | 不直接使用 | 不直接使用 | 部分类型或上限涉及 | 使用 | 不使用该长度因子 |
| 本次有效削韧量 | 不直接使用 | 不直接使用 | 不直接使用 | 不作为总韧性因子 | 使用 |
| 防御、抗性、适用易伤 | 使用 | 使用 | 使用 | 使用 | 使用 |
| 韧性减伤及结算阶段 | 需区分 | 需区分 | 需区分 | 视频明确提到瞬间 0.9 | 常规已处于击破状态 |

这张表最重要的用途是提醒：**先确定伤害属于什么，再确定它能接受哪些修改。**

## 8. 附加伤害不等于追加攻击

**【视频内容，约 13:50–14:30】**

### 8.1 不自动继承触发动作的类型

由战技或终结技触发一笔附加伤害，不意味着这笔附加伤害自动享受战技或终结技增伤。视频用“指定类型”与“非指定类型”加成对照，说明要判断伤害本身。

例如一般伤害加成、对应元素伤害加成，与某个限定动作类型的加成，适用范围不同。

### 8.2 数值来源可能不是当前行动者

视频约 14:10–14:22 对比：

- 知更鸟、貊泽、翡翠相关附加伤害，按其举例分别读取对应角色的面板。
- 停云战技、天赋提供的附加伤害，视频指向赐福对象的面板。

这说明至少要区分：谁提供效果、谁触发效果、读取谁的数值。**本段并不等于已经给出了这些角色每个效果的全部属性归属公式**，具体能力仍需看完整技能规则。

### 8.3 有伤害不一定算新的一次攻击

视频在 14:30 明确说，附加伤害无法触发某些要求独立攻击的效果。因此不能每出现一个数字就触发一次“攻击后”天赋，也不能把附加伤害一律排进追加攻击行动队列。

**【整理推导】**以下概念应分别理解：

| 概念 | 回答的问题 |
| --- | --- |
| 一次行动 | 谁获得一次执行行为的机会？ |
| 一次攻击 | 是否满足某个“发动攻击”的规则？ |
| 一段伤害 | 这次攻击拆出多少笔逻辑伤害？ |
| 附加伤害 | 某个效果是否额外造成伤害？ |
| 追加攻击 | 是否按规则触发一种额外攻击行为？ |
| 一个显示数字 | 表现层如何展示已经结算的结果？ |

## 9. 伤害稀释：用相对提升理解

### 9.1 同区继续叠加，收益为什么下降

**【视频内容，约 14:40–15:20】**已有加成越多，同样新增加成的相对收益越小。

**【整理推导】**设同区已有加成为 `x`，新增加成为 `Δ`：

```text
相对提升 = (1 + x + Δ) / (1 + x) - 1
         = Δ / (1 + x)
```

| 已有增伤 | 新增增伤 | 系数变化 | 相对提升 |
| ---: | ---: | --- | ---: |
| 0% | 50% | 1 → 1.5 | 50% |
| 50% | 50% | 1.5 → 2 | 33.33% |
| 150% | 50% | 2.5 → 3 | 20% |

在其他区不变时，每次增加的绝对伤害仍可能相同；下降的是相对原伤害的增长百分比。不是系统把后来的 50% 删除了一部分。

### 9.2 不同乘区为什么可能更划算

**【视频内容与整理推导，约 15:10】**

```text
同一区：1 + 0.5 + 0.5 = 2
两个独立区：1.5 × 1.5 = 2.25
```

在这个相同数值、相同覆盖率的示例下，分布在两个区比都堆在一个区高 `12.5%`。

但现实选项的数值、覆盖率、触发条件、持续时间和资源成本往往不同。**“稀有乘区”不自动等于“更强增益”。**一个很小且覆盖很差的独立增益，仍可能不如数值更大的常见增伤。

### 9.3 减防为什么被叫作“反向稀释”

**【视频内容，约 15:50】**视频指出减防收益曲线特殊。

**【整理推导】**因为减防在分母中，在未达到上限时，同样增加减防比例，可能获得越来越高的相对收益。继续用 80 级攻击方、95 级敌人：

| 减防与无视防御合计 | 防御系数 | 相对上一行提高 |
| ---: | ---: | ---: |
| 0% | 0.4651 | — |
| 20% | 0.5208 | 11.98% |
| 40% | 0.5917 | 13.61% |
| 60% | 0.6849 | 15.75% |
| 80% | 0.8130 | 18.70% |
| 100% | 1.0000 | 23.00% |

这只解释该公式与上限内的趋势。达到 100% 后，不能继续沿此趋势外推。

## 10. 三种体系的比较应该怎么看

**【视频内容，17:49–19:15】**作者比较了直伤、DOT、击破的乘区数量及触发限制。

| 体系 | 视频强调的优势 | 视频强调的限制 |
| --- | --- | --- |
| 直伤 | 可利用攻击、增伤、双暴等较多成长来源；出伤通常较直接 | 对多项属性和配队增益有要求，单次伤害仍不代表循环表现 |
| DOT | 常规不依赖双暴；可借敌方行动和引爆机制出伤 | 可能需要施加、叠层、等待；换目标、换波次与引爆频率影响表现 |
| 击破 | 有独立的等级基础和击破成长路线；超击破把削韧能力转为输出 | 依赖破韧及击破窗口，普通增伤与双暴不能简单套用 |

作者对体系强弱的口语评价属于当时角色、敌人与环境下的判断。**不能据此得出“乘区更多的体系永远更强”。**基础倍率、可获得增益、触发频率、敌人机制和输出窗口同样重要。

## 11. DPR：从一次伤害转向单位行动值的输出

### 11.1 视频中的定义

**【视频内容，19:20–19:30】**视频先对比 DPS，再给出 DPR 的计算口径：

```text
DPR = (统计区间总伤害 / 该区间消耗的行动值) × 100
```

作者称其为 Damage Per Round，但这里具体按**每 100 行动值的伤害**标准化。阅读不同攻略时，应先确认“Round”是否使用同一口径。

它不等于“一条 Action 记录的伤害”，也不等于“现实一秒钟内的伤害”。同一角色行动、队伍统一行动轴、关卡轮次计时，也不能无条件混为同一种回合。

### 11.2 速度提高的是机会，不是单次伤害乘数

**【视频内容，约 19:40–20:10】**速度和行动提前通过增加行动机会提高区间总输出。

视频以每次伤害相同、速度从 100 提高到 120 的理想情况说明频率收益。**【整理推导】**实际有限窗口里，行动次数是离散的，还受初始行动位置、资源供应、控制和技能循环影响，不能保证速度提高 20% 时任意短窗口伤害都恰好提高 20%。

### 11.3 队伍也能决定某个角色的输出频率

**【视频内容，约 20:20–20:50】**飞霄、黄泉等角色的关键输出资源与队友行为相关。不能只根据该角色自身速度推算终结技次数，还要考虑队伍行为频率、资源上限和溢出。

### 11.4 平均值不能表达全部战斗体验

**【视频内容，约 21:00–21:10】**输出曲线、爆发时点和伤害分布也重要。

**【整理推导】**同样的 DPR，可能一个队伍前期就能击杀，另一个必须等较久才能打出大数字。过量伤害、换波后的资源、目标数量和有效伤害分布，也会改变实际通关效果。

## 12. 对后续伤害与天赋设计的启示

以下是**【整理推导】**，属于从视频得到的概念整理，不是对官方源码的描述，也没有在本次任务中修改项目实现。

### 12.1 先定义伤害种类，再定义允许参与的乘区

普通直伤、技能 DOT、击破 DOT、击破和超击破共享部分防御、抗性处理，但基础量和增幅资格不同。把所有伤害都塞进一个“攻击力 × 倍率 × 全部 Buff”表达式会产生系统性错误。

### 12.2 每笔伤害需要足够清楚的上下文

至少应能回答：

- 谁提供效果，谁触发，最终读取谁的属性？
- 伤害是什么元素、什么类别，是否属于独立攻击？
- 能否暴击，适用哪些增伤和易伤？
- 哪些值使用施加时快照，哪些值结算时重新读取？
- 发生在破韧前、破韧瞬间，还是破韧之后？
- 它属于哪个行动，行动内又包含多少独立伤害来源？

这些问题会直接决定天赋能否正确触发，也决定伤害记录能否解释结果。

### 12.3 天赋来源和伤害乘区是两个维度

一个天赋可以：

1. 提供攻击、暴击或其他属性修改。
2. 对满足条件的伤害提供增伤或易伤。
3. 改变技能倍率、削韧或某类伤害的特殊参数。
4. 产生一笔新的附加伤害。
5. 触发一次额外攻击或改变资源与行动频率。

这些结果最终影响不同环节。天赋不应天然等于“最后再乘一个百分比”，伤害计算也不宜依赖一串具体角色名称来决定所有行为。

### 12.4 将单次伤害解释与行动汇总区分

一次行动中可能有普通伤害、附加伤害、击破、超击破等多笔结果。每笔结果可以保留自身来源与计算因素，行动层再汇总总伤害，表现层按演出节奏逐步呈现。

动画播放几次、UI 跳出几次数字，不应反过来决定“攻击后天赋”触发几次。这是视频中附加伤害与独立攻击区别带来的直接启示。

### 12.5 调试时需要解释“为什么是这个数字”

有用的伤害明细应包含基础量、适用加成、各乘区结果、暴击状态、目标防御与抗性，以及关键快照和阶段信息。只保存最终整数，将很难判断是数值配置、触发条件还是结算顺序出了问题。

## 13. 当前仍需另行核验的内容

这份视频足以建立乘区认知，但不能独立承担全部战斗规则规格。正式复现前还需要核验：

1. 当前版本的抗性上下限、异常数值处理及特殊敌人例外。
2. 所有减伤来源的叠加规则，护盾吸收与伤害数值的关系。
3. 视频所说“击破瞬间按 0.9”的现版本实测与技能例外。
4. 击破系数完整精度、各等级表、元素 DOT 和控制效果的完整公式。
5. 每种 DOT 的属性归属、快照字段、叠层、刷新与引爆时机。
6. 多段伤害的暴击判定粒度，以及破韧当段的削韧如何参与后续计算。
7. 各角色附加伤害、追加攻击和超击破来源的具体适用条件。
8. 取整、最小伤害、免疫、过量伤害与伤害统计口径。
9. 忘归人、星期日等角色正式上线后的技能；视频里的预测不能替代正式资料。

## 14. 快速复习

| 容易混淆的说法 | 应如何理解 |
| --- | --- |
| “加 20% 攻击就是伤害提高 20%” | 要看基础攻击、已有加成、固定攻击及技能缩放 |
| “所有增伤都乘起来” | 先判断适用性，同一加算区通常相加 |
| “受到伤害提高就是普通增伤” | 易伤与造成伤害加成属于不同环节 |
| “DOT 都不吃增伤” | 技能 DOT 与击破 DOT 不同 |
| “击破和超击破只是倍率不同” | 基础输入也不同：目标总韧性与本次有效削韧不能互换 |
| “有伤害数字就算一次攻击” | 附加伤害、攻击事件、行动记录和显示数字需要区分 |
| “稀释意味着加成被吞了” | 通常是相对于已有总量，新增收益占比下降 |
| “稀有乘区一定最好” | 数值大小、覆盖率和触发代价同样重要 |
| “伤害高的一击一定更强” | 要结合单位行动值内的频率、循环和输出窗口 |
| “天赋应该统一进独立乘区” | 天赋是效果来源，具体可以修改多种规则 |
